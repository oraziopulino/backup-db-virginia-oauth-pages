Backup DB Virginia

Backup DB Virginia è un'utilità privata utilizzata dalla titolare dell'account per conservare nel proprio Google Drive copie cifrate di sicurezza di un database PostgreSQL.

I file vengono cifrati sul computer prima del caricamento. L'applicazione usa Google Drive esclusivamente per creare, verificare, elencare ed eliminare i propri file di backup cifrati.
